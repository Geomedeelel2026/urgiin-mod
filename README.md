# Ургийн мод

Гэр бүлийн ургийн модыг вэб хуудсаар хөтлөнө. GitHub Pages дээр үнэгүй байршуулна. Өгөгдөл нь Firebase-д хадгалагдана.

- **Харах код** мэдэх хүн л модыг үзнэ. Бусдад хаалттай.
- **Засах код** мэдэх хүн хүн нэмж, засна.
- Кодыг нэг удаа оруулахад тухайн төхөөрөмж санана.
- Нэг хүний хийсэн өөрчлөлт бусдын дэлгэц дээр шууд гарч ирнэ.

## Файлууд

| Файл | Юу вэ |
| --- | --- |
| `index.html` | Хуудас өөрөө |
| `config.js` | Firebase-ийн тохиргоо (2-р алхамд бөглөнө) |
| `database.rules.json` | Firebase-ийн хамгаалалтын дүрэм |
| `.nojekyll` | GitHub Pages-д зориулсан хоосон файл |

---

## 1. Firebase төсөл үүсгэх (≈10 минут)

1. <https://console.firebase.google.com> руу Google бүртгэлээрээ орно.
2. **Add project** дарж нэр өгнө (жишээ нь `manai-urgiin-mod`). Google Analytics шаардлагагүй.
3. Зүүн цэснээс **Build → Realtime Database → Create Database** дарна.
   - Байршил: **Singapore (asia-southeast1)** нь Монголд ойр.
   - **Start in locked mode** сонгоно.
4. **Rules** таб руу орж, бүх текстийг `database.rules.json`-ийн агуулгаар солиод **Publish** дарна.
5. **Data** таб руу орж хоёр код үүсгэнэ.
   - `+` дарж **Key** = `config` гэж бичнэ.
   - Дотор нь `+` дарж **Key** = `viewCode`, **Value** = **харах код** (жишээ нь `urag-2026`) гэж бичнэ. Энэ кодыг бүх хамаатан садандаа хэлнэ.
   - Мөн `+` дарж **Key** = `joinCode`, **Value** = **засах код** (жишээ нь `Borjigin-Zasah-7`) гэж бичиж **Add** дарна. Энэ кодыг зөвхөн итгэдэг цөөн хүндээ хэлнэ. Засах кодоор харах ч боломжтой.
   - `viewCode`-ийг үүсгэхгүй орхивол холбоостой хэн ч модыг харж чадна.
6. **Build → Authentication → Get started** дарна. **Sign-in method** таб дээр **Anonymous**-ийг идэвхжүүлж **Save** дарна.

## 2. `config.js`-ийг бөглөх

1. Firebase-ийн **⚙ Project settings** руу орно. **Your apps** хэсэгт **`</>`** (Web) дээр дарж апп бүртгэнэ (Hosting шаардлагагүй).
2. Гарч ирсэн `firebaseConfig = { ... }` доторх утгуудыг `config.js` дотор `window.FIREBASE_CONFIG = { ... };` болгож хуулна. Файл доторх жишээг хараарай.
   - **`databaseURL`** байгаа эсэхийг заавал шалгаарай. Байхгүй бол Realtime Database хуудасны дээд хэсэгт байгаа `https://...firebasedatabase.app` хаягийг нэмж бичнэ.

## 3. GitHub дээр байршуулах

1. <https://github.com/new> дээр шинэ **Public** repo үүсгэнэ (жишээ нь `urgiin-mod`).
2. **Add file → Upload files** дарж `index.html`, `config.js`, `.nojekyll`, `README.md` файлуудыг чирж оруулаад **Commit changes** дарна.
   - `.nojekyll` харагдахгүй байвал алгасаж болно.
3. Repo-ийн **Settings → Pages** руу орно. **Source: Deploy from a branch**, **Branch: `main` / `(root)`** сонгоод **Save** дарна.
4. 1–2 минутын дараа хуудас `https://ТАНЫ-НЭР.github.io/urgiin-mod/` хаягаар нээгдэнэ.

## 4. GitHub хаягийг Firebase-д зөвшөөрөх

Firebase-ийн **Authentication → Settings → Authorized domains → Add domain** хэсэгт `ТАНЫ-НЭР.github.io` гэж нэмнэ.

## 5. Хуваалцах

Хамаатан садандаа хуудасны холбоос болон **харах кодыг** илгээнэ. Засах ёстой хүмүүст **засах кодыг** тусад нь хэлнэ. Хуудсыг нээхэд код асууна. Харах эрхтэй хүн **+ Хүн нэмэх** дарахад засах код асууна.

Та өөрөө эхлээд хуудсаа нээж **засах кодоо** оруулаад хүмүүсээ нэмээрэй.

## Түгээмэл асуулт

**Эхэнд яагаад хоосон байна вэ?** Firebase-д одоохондоо хүн нэмээгүй учраас. **Жишээ үзэх** товч дарж жишээ модыг ачаалж болно. Дараа нь **⋯ → Бүгдийг арилгах** дарж хоослоно.

**Хуучин өгөгдлөө (Claude дээрх хувилбараас) яаж шилжүүлэх вэ?** Хуучин хуудаснаас **⋯ → Өгөгдлийг JSON-оор хуулах** дарна. Шинэ хуудаснаас **⋯ → JSON-оос оруулах** дарж буулгана.

**"Firebase-д холбогдож чадсангүй" гэж гарвал?** `config.js` доторх утгууд, ялангуяа `databaseURL`, мөн 4-р алхмыг шалгаарай.

**Кодоо солих бол?** Firebase **Data** таб дээр `config/viewCode` эсвэл `config/joinCode`-ийн утгыг солино. Аль хэдийн нэвтэрсэн төхөөрөмжүүд `viewers`, `editors` доор бүртгэлтэй үлдэнэ. Тэдгээрийн эрхийг хасах бол тэндээс устгана. Бүгдийг нь хасвал хүн бүр шинэ кодоо дахин оруулна.

**Код ил болсон бол?** Кодоо солиод, `viewers` болон `editors`-ийг бүхэлд нь устгана.

**Нөөц хуулбар:** Хааяа **⋯ → Өгөгдлийг JSON-оор хуулах** дарж хадгалаарай. Firebase **Data** таб дээрх **⋮ → Export JSON** ч бас ажиллана.

**Үнэ:** Firebase-ийн үнэгүй (Spark) багц гэр бүлийн модонд хангалттай.
